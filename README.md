# BACI Phase 2 Impact Dashboard

Responsive GitHub Pages dashboard for BACI Phase 2 programme-level session tracking.

## Main data file

Place:

`01_Programme_Summary.csv`

inside:

`data/`

## Current dashboard behavior

- Header is center aligned.
- Dashboard title is `Impact Dashboard`.
- Programme Launch Name filter is hidden.
- KPI cards are removed.
- Programme table hides these columns:
  - Unique_Children_Atleast_1_Session
  - Region
  - Target_Outreach
  - Total_Session_Attendance
  - Sessions_Conducted
  - Average_Sessions_Per_Child
- Users can download:
  - all visible-column data
  - currently filtered visible-column data
